IL2 Korea ALM v1.0.2 - UPDATE button patch

Changes:
- removes the update-check section from Options;
- adds an UPDATE button immediately left of OPTIONS in the main bottom bar;
- startup GitHub check stays silent;
- UPDATE button turns red when a newer official release is available;
- clicking a red UPDATE button opens the update dialog immediately;
- clicking the normal UPDATE button performs a manual update check;
- update status remains correct after a theme change.

Copy all files/folders from this patch into the repository root and replace existing files.
Then run build_windows.bat to rebuild the executable.
